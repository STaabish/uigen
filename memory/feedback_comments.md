---
name: Use comments sparingly
description: Only add comments to complex/non-obvious code
type: feedback
---

Only comment complex or non-obvious code. Do not add comments to self-explanatory code.

**Why:** User preference for clean, minimal code.

**How to apply:** When writing or editing code, skip comments unless the logic genuinely requires explanation to understand. Never add comments like "// Hash password", "// Find user", "// Validate input", etc.
